Skills For Real Engineers は、[Matt Pocock](https://www.aihero.dev) が毎日使っていると語るエージェント向けスキルの集まりです。開発プロセスを丸ごと握るフレームワークとは対極にあり、スキルは小さく組み合わせやすいままなので、主導権はあなたの手に残り、自分で編集もできます。

### しくみ

仕事の大半は、アイデアから出荷までの 1 本のメインフローに沿って進みます。

1. **grill-with-docs** は、インタビューでアイデアを磨き、得られたことを用語集と ADR に記録します。
2. **to-spec** は、会話を仕様にまとめます。複数セッションにまたがる開発向けです。
3. **to-tickets** は、仕様をトレーサーバレット型のチケットに分け、ブロック関係でつなぎます。
4. **implement** は 1 つのチケットを実装し、**implement-spec** は仕様全体を並列のサブエージェントで実行します。どちらも **tdd** を回し、最後に **code-review** で締めます。
5. **retro** は、セッションを振り返り、コードではなくエージェントの環境を変えます。

ほかの仕事は、このフローに合流します。届いた issue には **triage**、1 セッションでは大きすぎて見通しも立たない取り組みには **wayfinder** を使います。**ask-matt** はルーターで、今の状況にどのスキルが合うかを尋ねられます。

### 理念

最もよくある失敗は、あなたとエージェントの認識のずれです。そのためスキルは、質問攻め（グリリング）のセッションと共通言語づくりから始まります。スキルは短く保ち、互いを呼び出し合います。数行だけのものも多くあります。小さなスキルは、その土台にあるインタビューの基本部品 **grilling** に頼っています。

### はじめに

```
claude plugin install mattpocock-skills@claude-plugins-official
```

リポジトリごとに一度 `/setup-matt-pocock-skills` を実行し、課題トラッカー、トリアージ用ラベル、ドキュメントの配置を設定します。そのあと、次の変更で `/grill-with-docs` を試すか、どこから始めるか迷ったら `/ask-matt` を使ってください。

### このデッキについて

どのカードもプラグインの一覧にあるスキルで、**ask-matt** がルーターです。凍結された `misc/` と未完成の `in-progress/` のスキルはカードにしていません。**Sprint** ビューでは、Sharpen から Improve の順にスキルが並び、用語とセットアップのスキルがその脇に置かれます。
