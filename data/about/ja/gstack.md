gstack は、Claude Code をスラッシュコマンドで構成されたエンジニアリングチームに変えます。Y Combinator の社長兼 CEO である [Garry Tan](https://x.com/garrytan) が作り、YC を率いながら毎日これでコードを出荷しています。

### しくみ

各スキルは、CEO、エンジニアリングマネージャー、デザイナー、スタッフレビュアー、QA リード、セキュリティ担当、リリースエンジニアなど、1 つの役割を演じます。スキルはスプリントの順に動きます。

**Think → Plan → Build → Review → Test → Ship → Reflect**

各ステップは、次のステップが読むものを書き出します。`/office-hours` は設計ドキュメントを書き、`/plan-ceo-review` がそれを読みます。`/plan-eng-review` はテスト計画を書き、`/qa` が引き継ぎます。`/review` がバグを見つけ、`/ship` が修正済みかを確認します。`/browse` はヘッドレス Chromium ブラウザを操作し、`/qa` がアプリをクリックして回り、スクリーンショットを撮れるようにします。`/careful` は破壊的なコマンドの前に警告し、`/freeze` は特定のディレクトリ外の編集を止めます。

### はじめに

リポジトリを `~/.claude/skills/gstack` にクローンし、`./setup` を実行します。そのあと、次の順に試してください。

1. `/office-hours` を実行し、作っているものを説明する。
2. 機能のアイデアに `/plan-ceo-review` を実行する。
3. ブランチに `/review` を、ステージング環境の URL に `/qa` を実行する。

### このデッキについて

どのカードも 1 つのスキルです。**Sprint** ビューでは、スプリントの順に並びます。
