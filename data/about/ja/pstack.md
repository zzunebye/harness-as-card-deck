**速く進みたいなら、まず深く掘る。** pstack は、React コアチームの Lauren Tan（[poteto](https://x.com/poteto)）が Cursor で出荷するときに使っているスキル群です。目標は、より少ないコードでより高い品質を得ること。そうすれば、複数のエージェントを並列に走らせても、その一つひとつを信頼できます。

### しくみ

厳密さが必要なタスクは、すべて 1 つのルーター `/poteto-mode` から始まります。ルーターは依頼を読み、バグ修正、機能開発、調査、babysit、出荷など 23 のプレイブックのどれかに当てはめ、そのプレイブックの手順を ToDo リストにコピーします。各ステップが発火するたびに、ルーターはそのステップに必要なスキルを読み込みます。`how` と `why` は調査を、`architect` と `arena` は設計の比較を、`swarm` は検証を、`unslop` は文章の推敲を担当します。判断のたびに、その根拠となる原則（たとえば *Laziness Protocol* や *Prove It Works*）が示されるので、レビュアーはその選択をルールに照らして確認できます。

pstack は、モデルの得意分野で仕事を振り分けます。定型的なコードは高速なコードモデルへ、最も難しい変更、文章、判断は最も強いモデルへ回します。

### はじめに

```
/plugin marketplace add cursor/plugins
/plugin install pstack@cursor-plugins
```

最初に `/setup-pstack` を一度実行してモデルを選び、そのあと `/poteto-mode <task>` でタスクを始めます。

### このデッキについて

♠ はルーター、♥ はそのプレイブック、♦ はプレイブックが呼び出すスキル、♣ はスキルが参照する原則、★ はサブエージェントです。
