Superpowers는 [Jesse Vincent](https://blog.fsck.com/2025/10/09/superpowers/)가 만든 코딩 에이전트용 개발 방법입니다. 스킬 모음과, 에이전트가 모든 작업 전에 맞는 스킬을 먼저 찾게 하는 시작 지시문으로 이루어져 있습니다. 스킬이 맞으면 에이전트는 그 워크플로를 따라야 합니다.

### 동작 방식

에이전트는 코드부터 쓰지 않습니다. 하나의 파이프라인을 따릅니다.

1. **brainstorming**은 무엇을 원하는지 묻고, 승인할 수 있는 설계로 정리합니다.
2. **using-git-worktrees**는 격리된 브랜치를 열고, 변경 전에 테스트가 통과하는지 확인합니다.
3. **writing-plans**는 설계를 2~5분짜리 작업으로 나누고, 각 작업에 정확한 파일 경로와 검증 방법을 붙입니다.
4. **subagent-driven-development**는 작업마다 새 서브에이전트에 맡기고 결과를 리뷰합니다.
5. **test-driven-development**는 실패하는 테스트를 먼저 쓰게 하고, 테스트보다 먼저 쓴 코드는 삭제합니다.
6. **requesting-code-review**는 작업 사이에 실행되고, 치명적인 문제가 있으면 작업을 멈춥니다.
7. **finishing-a-development-branch**는 테스트를 실행하고, 머지, PR 열기, 브랜치 유지, 폐기 중에서 고르게 합니다.

에이전트는 승인된 계획을 혼자서 두어 시간 동안 진행할 수 있습니다.

### 철학

테스트를 먼저 씁니다. 추측하지 않고 절차를 따릅니다. 코드를 단순하게 유지합니다. 성공을 주장하기 전에 검증합니다.

### 시작하기

```
/plugin install superpowers@claude-plugins-official
```

스킬은 저절로 로드되므로 평범한 요청으로 시작하면 됩니다.

### 이 덱에서는

모든 카드는 스킬입니다. **스프린트** 보기는 스킬을 파이프라인 순서로 배치합니다.
